# Fate Core Sheets — видение продукта

Интерактивное веб-приложение для создания, хранения и экспорта персонажей **Fate Core** с сеттингом «Ведьмак» и ИИ-помощником на Gemini. Игра за столом: печать или PDF для Tabletop Simulator.

* Визуальный язык: `docs/design/DESIGN.md`, референс `docs/design/reference.png`.
* Правила листа (аспекты, пирамида, трюки, восстановление): `docs/agents/product.md`. При расхождении побеждает `product.md`.

## Экраны

**Каталог персонажей.** Верхняя панель (логотип, вход/выход, «Создать персонажа»), поиск, сетка карточек: аватар, имя, концепция, индикаторы стресса, меню (Открыть, Скачать PDF, Дублировать, Удалить). Пустая коллекция: подпись и кнопка создания первого героя.

**Мастер создания.** Шаги по порядку: аспекты, навыки, трюки, итог. Правила — `product.md`.

**Лист персонажа.** Верхняя панель: «К списку», индикатор сохранения (облако/локально), «Экспорт в PDF». Раскладка из трёх колонок описана в DESIGN.md, раздел 4. Содержимое: паспорт, пять аспектов, пирамида навыков, трюки, стресс (физический, ментальный), три последствия.

## ИИ (Gemini)

Помощник по трюкам (оценка и три варианта) — подробности в `product.md`. Планируется: помощь по аспектам и случайный концепт. Свой ключ задаётся в настройках, без ключа приложение работает полностью.

## Данные

* Firebase Auth: Google и Email/пароль.
* Firestore: `users/{uid}/characters/{charId}`.
* Аватары: загрузка с ПК, сжатие.
* Нет авторизации или сети — прозрачное сохранение в `localStorage`.

## Инфраструктура

Vite + React + TypeScript + Tailwind. GitHub Pages (`Danchel77/fate-core-sheets`), GitHub Actions на пуш в `main`.

## Вне текущего объёма

Универсальный Fate Core и переключатель сеттингов — после «Ведьмака».
