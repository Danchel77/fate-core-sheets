# DESIGN.md — Visual Direction & Asset Guidelines

## 1. Two Distinct Visual Modes
Сервис строго разделяет экранный интерфейс и версию для печати. Никогда не смешивай эти стилистики на одном экране.

### Mode A: Web Interface (Pathfinder CRPG Reference)
- **Метафора:** открытая книга/фолиант с плотными пергаментными страницами, лежащая на тёмном деревянном столе.
- **Референсы (только мудборд, ассеты не копировать):** `references/char_sheet_1.png`, `references/char_sheet_2.png` — скриншоты Pathfinder: Kingmaker / Wrath of the Righteous, © Vasily Levinov / Pavel Turchin, 2020.
- **Интерактивность:** тактильная — объёмные чекбоксы стресса, наглядные жетоны судьбы, закладки-вкладки, лёгкие тени страниц.
- **Табу:**
  - Чистый чёрный фон (`#000000` / `#080808`) и «тёмная плоская админка».
  - Имитация фэнтезийных рамок через `clip-path` и срезанные углы.
  - Огромные пустые дыры в сетке навыков: незаполненные слоты пирамиды рисуются аккуратными контурами, чтобы блок держал прямоугольную форму страницы.
- **Мобильные:** интерфейс полноценно работает на телефоне, включая мастер создания (решение пользователя). Значит, книга не «сжимается в кашу»: на узком экране она разворачивается в одну колонку с теми же токенами.

### Mode B: Print Sheet (Official Fate Core Reference)
- **Метафора:** типографский бланк Fate Core, один лист = один персонаж.
- **Формат:** **A4 горизонтально** (297 × 210 мм), поля минимальные, фон белый (экономия тонера).
- **Стиль:** строго чёрно-белый: фон `#ffffff`, плашки заголовков `#000000` со скошенным правым нижним углом, чёткие рамки полей, крупные цифры `1, 2, 3, 4` и `2, 4, 6` внахлёст на ячейки стресса и последствий.
- **Брендинг:** официальный логотип **FATE CORE SYSTEM (™)** не используется (чужая торговая марка). В правом верхнем углу — нейтральная надпись «Fate Core» шрифтом листа. Логотипы сеттингов (Ведьмак, D&D) также не нужны.
- **Геометрия:** 1-в-1 с официальным бланком «Студии 101» (`references/Fate_Core_Character_Sheet_RU.pdf`): блоки «Персонаж», «Аспекты» (5 полей), «Навыки» (5 × 5), «Дополнения», «Трюки», физический и ментальный стресс, последствия 2/4/6 + второй слот «Лёгкое».
- **Сверка:** печатный экран считается готовым только после наложения макета на референс (см. Definition of Done в `AGENTS.md` §5).

## 2. Portrait (Портрет персонажа)
- Рамка портрета есть и в веб-листе, и на печати.
- **Загрузка:** файл с компьютера (JPEG/PNG/WebP), без ИИ-генерации.
- **Редактор кадрирования:** перетаскивание + масштабирование внутри рамки, картинка всегда покрывает рамку (масштаб не меньше «cover»), сохраняется нормализованное состояние `{ x, y, scale }` (0…1 от размера кадра).
- **Хранение:** исходник уменьшается до 1200 px по длинной стороне и хранится Blob'ом в IndexedDB; в JSON персонажа попадает только ключ и параметры кадрирования.
- **Печать:** на печатный лист портрет выводится в градациях серого.

## 3. Asset Sourcing Protocol (No Hand-Drawn SVGs)
Рисовать сложную графику кодом запрещено. Для оформления агент обязан находить и скачивать готовые ассеты из открытых источников (или показывать пользователю варианты на выбор):
- **Текстуры (`public/assets/textures/`):** бесшовная состаренная бумага/пергамент для страниц, тёмное дерево/кожа для фона вокруг книги.
- **Рамки и разделители (`public/assets/frames/`):** рамка портрета, угловые виньетки, плашки заголовков.
- **Иконки (`public/assets/icons/`):** только проверенные библиотеки с открытой лицензией (например, *Game-icons.net* — CC BY 3.0, *Lucide* — ISC).
- **Шрифты (Google Fonts, OFL):** обязательна поддержка кириллицы; выбираются на визуальном пробнике.
- **Лицензии:** допускаются только CC0, OFL, public domain или явно разрешающие использование ассеты. Каждый скачанный файл фиксируется в `public/assets/CREDITS.md`: имя файла, автор, источник (URL), лицензия. Без записи в CREDITS ассет в проект не попадает.

## 4. Typography Requirements
- Заголовки — антиква с характером (книжная, слегка контрастная), текст — читаемая антиква или гротеск.
- Оба шрифта обязаны поддерживать кириллицу и иметь лицензию OFL (для встраивания в PDF через `pdf-lib`).
- Финальная пара шрифтов утверждается на Phase 2 вместе с токенами; до этого в макеты не зашивается.

## 6. Responsive Rules
- Брейкпоинты: 360 / 768 / 1024 / 1440.
- Мастер на телефоне: одна колонка, крупные цели нажатия (≥ 44 px), прогресс закреплён сверху.
- Веб-лист на телефоне: пирамида навыков не должна обрезаться — уменьшается шрифт и отступы, а не содержимое.
- Горизонтальная прокрутка страницы запрещена на всех ширинах.

## 7. Print Fidelity Rules
- CSS: `@page { size: A4 landscape; margin: 0 }`, печатный лист ровно 297 × 210 мм.
- Никаких цветов и теней на печати, только чёрный/белый и серый для текста.
- Проверка: скриншот печатного экрана накладывается на рендер официального бланка; допускаются отклонения только по геометрии блоков (см. `AGENTS.md` §6).
