# Дизайн-система Fate Core Sheets

Референс: `docs/design/reference.png` (скриншот игрового интерфейса, автор Pavel Turchin, 2020).
Берём **язык**: чёрный фон, золотые ленты-заголовки, угловые рамки, капитель в заголовках, плотные таблицы с мелкими подписями.
Не берём **ассеты**: портреты, иконки, орнамент нарисованы автором. Всё делаем в CSS/SVG. Содержимое — Fate, а не D&D (характеристики STR/CON, заклинания, классы не переносим).

Это заменяет общий скилл `ui-design` для этого проекта. Если они расходятся — прав этот файл.

## 1. Токены

Цвета измерены по референсу, отмечено «своё» — выбрано нами. Добавить в `tailwind.config` и больше нигде цвета не задавать.

| Токен | Hex | Для чего |
|---|---|---|
| `ink` | `#000000` | фон страницы |
| `ink-raised` | `#0d0d0d` | поле ввода, ячейка таблицы |
| `ink-frame` | `#1a1a1a` | неактивные кнопки |
| `panel` | `#141414` | подложка блока и модального окна (своё) |
| `line` | `#292319` | тонкие разделители, границы блоков |
| `gold` | `#987849` | ленты-заголовки, рамки, основная кнопка |
| `gold-light` | `#a68354` | hover, заполнение полос, активные метки |
| `gold-dim` | `#775e39` | только декор (углы, линии). **Не для текста**: контраст ниже 4.5 |
| `wine` | `#37242c` | верхняя панель, активная вкладка, hover вторичной кнопки |
| `text` | `#e8e8e8` | основной текст |
| `text-muted` | `#a8a090` | подписи, вторичный текст (своё) |
| `danger` | `#b0493f` | ошибка, тяжёлое последствие (своё) |
| `warn` | `#c9a227` | предупреждение (своё) |


Конфиг (`tailwind.config`, секция `theme.extend`): если файл `.js` или `.ts`, определи по репозиторию.

```js
colors: {
  ink: { DEFAULT: '#000000', raised: '#0d0d0d', frame: '#1a1a1a' },
  panel: '#141414',
  line: '#292319',
  gold: { DEFAULT: '#987849', light: '#a68354', dim: '#775e39' },
  wine: '#37242c',
  text: { DEFAULT: '#e8e8e8', muted: '#a8a090' },
  danger: '#b0493f',
  warn: '#c9a227',
},
```

Классы получаются такие: `bg-ink`, `bg-ink-raised`, `border-line`, `bg-gold`, `text-gold-light`, `border-gold-dim`, `bg-wine`, `text-text`, `text-text-muted`.

Текст на золотой ленте — `ink`. Больше цветов не вводить.

Фон страницы — чистый `ink`, без градиентов и текстур. Углы **острые**: `rounded-none` (максимум `rounded-sm`).

## 2. Типографика

Два шрифта и два цвета текста — этого достаточно. `Cinzel` (`font-fantasy`) — имена, заголовки, числа-акценты. `Inter` (`font-sans`) — всё остальное. Основной текст только `text-text`, второстепенный только `text-text-muted`; золото — акцент, а не цвет текста.

| Роль | Классы |
|---|---|
| Имя персонажа | `font-fantasy text-3xl text-text tracking-wide [font-variant-caps:small-caps]` |
| Заголовок на ленте | `font-fantasy text-base text-ink [font-variant-caps:small-caps] tracking-wide` |
| Название элемента в блоке (трюк, навык, аспект, число последствия) | `font-fantasy text-sm text-text` |
| Пояснение под названием (описание трюка, текст аспекта) | `font-sans text-sm text-text` |
| Подпись поля | `font-sans text-xs uppercase tracking-wider text-text-muted` |
| Обычный текст, вторичное | `font-sans text-xs text-text-muted` |
| Числа | всегда добавляй `tabular-nums` |

Правило иерархии одно на весь проект: **название — крупнее и светлое, пояснение — мельче и приглушённое**. Обратный порядок (приглушённое название над светлым текстом) запрещён — из-за него аспекты выглядели перевёрнутыми рядом с трюками.

Размеры только из набора: **12, 14, 16, 18, 20, 24, 30 px**. Других быть не должно, включая `text-[13px]` и подобное. Минимум — **12px**, мельче нельзя, это проверяет `capture.mjs`.

Английских дублей подписей нет: ни `High Concept`, ни `Trouble`, ни английских названий навыков. Русский термин и всё.

## 3. Компоненты (`src/components/common/`)

Каждый в своём файле. Нет компонента — создай по рецепту. Для проверок в сценариях компонент ставит data-атрибут на корневой элемент: `data-ribbon` (SectionRibbon), `data-kit="sheet-block"` (блок листа), `data-kit="fate-point"` (очко судьбы), `data-stress-box`, `data-btn`, `data-kit="field-label"` (FieldLabel), `data-kit="stat-row"` (строка StatTable), `data-kit="bar"` и `data-kit="bar-fill"` (трек и заполнение Bar), `data-kit="input"` (Input), `data-kit="filter-tab"` и `data-active` (Tabs).

Эти атрибуты — часть контракта компонента: по ним сценарий `foundation` проверяет цвета и размеры. Удалил атрибут — фундамент красный.

**SectionRibbon** — заголовок секции. Золотая лента на всю ширину блока, компактная:
`relative bg-gold text-ink font-fantasy text-lg leading-tight text-center py-1 [clip-path:polygon(0_50%,14px_0,calc(100%-14px)_0,100%_50%,calc(100%-14px)_100%,14px_100%)]`.
Общая высота ленты — **не больше 34px**: это проверяет `foundation`. Прежняя лента была вдвое выше и съедала экран.

**Блок листа** (`SheetBlock`) — подложка вместо скобок, тот же язык, что у модального окна:
`section` → `flex min-w-0 flex-col`, сверху вплотную лента, под ней содержимое с `pt-2` и `gap-2`. **Заливки у блока нет** — блок отделяется от соседей только лентой, отступом `gap-5` и тонкой линией. Теней, скруглений и вторых рамок нет.

Угловые скобки `CornerFrame` из проекта **удалены** (2026-11-12), а с 19:52 того же дня у блоков убрана и подложка: **заливка у блока запрещена**, он держится лентой, линией и воздухом. Единственная поверхность ниже фона — интерактивные элементы (поле ввода, чип навыка, заметка): `bg-panel` (#141414) с границей `border-line`, hover `#1f1f1f`. Атрибутов `data-frame` и `data-corner` в разметке нет; проверка `F3` — «у блока нет заливки», проверка `F22` — высота ленты.

**FieldLabel + Value** — пара «подпись сверху, значение снизу» (подпись: `text-xs uppercase …`, значение: `text-text`, для имён — `font-fantasy`).

**FatePoint** — очко судьбы кружком, без заливки: доступное `size-3.5 shrink-0 rounded-full border border-gold bg-transparent`, потраченное `border border-dashed border-gold-dim bg-transparent`. Квадратов и заливки `bg-gold` больше нет. Переключается нажатием, `data-kit="fate-point"`, состояние в `data-spent`.

**StatTable** — таблица строк. Строка `flex items-center justify-between border-b border-line py-1.5`, слева название (`font-fantasy text-text`), справа число (`tabular-nums text-gold-light`). Для навыков в списке.

**StressBox** — клетка стресса: `size-7 border border-gold bg-ink`, отмеченная `bg-gold`, подпись номера внутри `text-xs tabular-nums`. Hover `border-gold-light`.

**Bar** — полоса (например счётчик слотов): трек `h-1 bg-ink border border-gold-dim`, заполнение `h-full bg-gold-light`.

**Button**
* основная: `bg-gold text-ink font-fantasy px-4 py-2 hover:bg-gold-light focus-visible:ring-2 focus-visible:ring-gold-light focus-visible:ring-offset-2 focus-visible:ring-offset-ink transition-colors duration-150`;
* вторичная: `border border-gold text-gold-light px-4 py-2 hover:bg-wine focus-visible:ring-2 focus-visible:ring-gold-light transition-colors duration-150`;
* неактивная: `bg-ink-frame text-text-muted cursor-not-allowed`.

**Tabs** (верхняя навигация): текст `font-fantasy uppercase tracking-wider`, неактивная `text-text-muted`, активная `text-text bg-wine`, под активной линия `border-b border-gold`.

**Input**: `bg-ink-raised border border-line text-text placeholder:text-text-muted px-3 py-2 focus-visible:border-gold focus-visible:ring-1 focus-visible:ring-gold`.

## 4. Раскладка листа персонажа

Анатомия взята из финального интерфейса Pathfinder (прислан человеком 2026-11-12), палитра — своя, тёмная. Ключевое: **мастер-деталь, а не три равные колонки**, и **один экран без прокрутки**.

Десктоп 1440px: `grid grid-cols-1 gap-6 lg:grid-cols-[320px_minmax(0,1fr)]`, контейнер `max-w-[1440px] mx-auto px-6`. Полезная высота — экран минус шапка и отступы (≈800px на 900px высоты), всё обязано в неё влезать. Мобильный (ниже 1024px): одна колонка в порядке сверху вниз, без горизонтального скролла.

| Область | Содержимое |
|---|---|
| Левая, 320px | плашка персонажа (логотип сеттинга одной строкой, портрет, имя, описание); «Очки судьбы»; «Стресс»; «Последствия» |
| Правая, `1fr` | «Навыки» на всю ширину; ниже две подколонки — «Трюки» и «Аспекты»; «Заметки» на всю ширину внизу |

Плашка персонажа — единственный «физический предмет» на листе: тонкая золотая рамка по периметру, внутри портрет **260×320** по центру, над ним логотип сеттинга **одной строкой** на уровне заголовков (капитель, `text-sm`, `text-gold`), под портретом имя и описание. Портрет не висит в воздухе: рамка плашки и есть его опора.

Сеттинг выбирается нажатием на логотип, отдельного выпадающего списка нет.

Как держим один экран:
* блок без заливки, `gap-5` между блоками, `gap-2` внутри;
* строка 28–32px, поле ввода по высоте строки;
* «Трюки» и «Заметки» имеют `max-height` и внутренний скролл — лист не растёт от количества трюков;
* ничего не растягиваем `flex-1`: равенство колонок получается из бюджета высоты, а не подгонкой.

Крайние состояния (проверяются механически):

| Что | Поведение |
|---|---|
| 4–5 трюков | блок «Трюки» ограничен по высоте, внутри свой скролл |
| Длинное имя | одна строка с обрезкой, полное значение — в `title` |
| Длинное описание | три строки, дальше обрезка |
| Нет портрета | рамка на месте с иконкой и подписью «Портрет», высота плашки не меняется |
| `skillCap` 5–6 | добавляется строка уровня, соседние блоки не сдвигаются |

Термин `Освежение` не используется — блок называется **«Восстановление»**. Очки судьбы — ровные кружки без заливки: доступные со сплошной золотой границей, потраченные с пунктирной.

## 5. Правила
* Контраст текста ≥ 4.5:1, подписи тоже.
* Интерактив: hover, `focus-visible`, `transition 150ms`.
* Иконки только `lucide-react`, `size-4` или `size-5`, `strokeWidth={1.5}`. В плотных строках таблиц и списков (слот навыка, строка трюка) допустимы `size-3` и `size-3.5` — иначе иконка ломает ритм строки.
* Длинный пользовательский текст: `truncate` или `line-clamp-N` и `title` с полным текстом.
* Рамки и ленты — единый стиль на всех экранах: каталог, мастер и лист выглядят одной системой.
* Скругления, тени и градиенты не использовать. Глубина — только ступенями `ink` → `ink-raised` → `ink-frame` и границами `line`.
* Состояния всех блоков — по `product.md`.

## 6. Чек-лист приёмки (для оркестратора)

Отвечать по пунктам: да / нет / не вижу.

1. Фон страницы чёрный, без градиентов.
2. Каждая секция начинается золотой лентой, лента компактная (не выше 34px), заголовок капителью Cinzel.
3. У блоков нет заливки и рамки: только лента, тонкая линия и воздух. Угловых скобок нет нигде. Подложка есть только у полей ввода, чипов и заметок, и она светлее фона.
4. Подписи полей мелкие, заглавными, приглушённые; названия и значения — светлые. Иерархия одна на всех блоках, перевёрнутых нет.
5. Числа выровнены столбцом.
6. Нет карточек внутри карточек.
7. Нет обрезанного текста («Пр…»), ничего не наезжает.
8. Пустые состояния оформлены, а не пустые прямоугольники.
9. На 390px одна колонка, нет горизонтального скролла.
10. На 1440 все три колонки заканчиваются на одной высоте.
11. Шрифтов два (Cinzel и Inter), размеров не больше шести, английских дублей подписей нет.
12. Общее впечатление рядом с `reference.png`: тот же язык (чёрное, золото, строгая типографика), а не светлая SaaS-панель.

## 7. Всплывающие слои и подсказки

Решено человеком 2026-11-12: окна — панель по центру с лентой-заголовком, вложенное открывается поверх со сдвигом и своей лентой; подсказки правил — тёмная плашка с золотой рамкой.

**Модальное окно.** Затемнение `bg-ink/80` на весь экран, панель по центру: `w-full max-w-2xl bg-panel border border-line`, лента с названием окна во всю ширину панели, ниже содержимое с отступом `px-4 py-3`. Закрытие: крестик `X` (lucide, `size-4`, `strokeWidth={1.5}`) в правом верхнем углу панели, `Escape`, клик по затемнению. Фокус переходит в окно при открытии и возвращается на кнопку-источник при закрытии; прокрутка страницы заблокирована. Скруглений и теней нет.

**Вложенное окно.** Открывается поверх родительского: та же панель, сдвиг `translate-x-6 translate-y-6`, поверх первого затемнения ещё одно `bg-ink/60`, своя лента. Родительское окно остаётся видимым и неактивным. `Escape` закрывает только верхнее.

**Подсказка (тултип) правил.** Триггер — текст с `decoration-gold-dim` подчёркиванием, `hover:text-gold-light`. Плашка: `absolute z-50 w-72 border border-gold bg-ink-raised p-3`, заголовок `font-fantasy text-sm text-gold-light [font-variant-caps:small-caps]`, текст `font-sans text-xs leading-relaxed text-text`. Появляется по клику, закрывается по клику вне и по `Escape`. На узком экране не должна вылезать за край: `max-w-[calc(100vw-2rem)]`.

**Поповер (например, «Восстановление»).** Тот же язык, что у подсказки: `border border-gold bg-ink-raised`, заголовок капителью, внутри — обычные `Button`/`Input`/`FieldLabel`. Иконок-вопросиков не используем: подчёркнутый термин и есть триггер.
