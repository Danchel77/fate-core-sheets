# AGENTS.md — Инструкция для AI-агентов (по канонам Anthropic)

## 1. Главные правила взаимодействия
* **Спрашивать, а не додумывать:** Каждое архитектурное, продуктовое или визуальное решение согласовывать с пользователем. Никогда не принимать решения молча.
* **Сначала план:** Перед внесением крупных изменений представлять план пользователю. Приступать к коду только после подтверждения.
* **Проверка качества:** После внесения изменений запускать `npm run typecheck` и `npm run build`. Никогда не оставлять код с ошибками типов или неразрешенными импортами.
* **Безопасность:** Никогда не коммитить секреты и API-ключи. Считывать через переменные окружения (`import.meta.env`).

---

## 2. Команды проекта
* `npm run dev` — запуск локального сервера разработки Vite.
* `npm run build` — сборка проекта для GitHub Pages (dist).
* `npm run preview` — просмотр продакшен-сборки.
* `npm run typecheck` — проверка типов TypeScript (`tsc --noEmit`).

---

## 3. Стандарты кода и модульности
* **Запрет на монолитный код:** Каждый компонент, сервис и утилита живет в отдельном файле. Никаких «все-в-одном» файлов.
* **TypeScript Strict Mode:** Строгая типизация всех сущностей Fate Core (Аспекты, Навыки, Трюки, Стресс). Никаких `any`.
* **Архитектура папок:**
  * `src/components/dashboard/` — экран каталога персонажей.
  * `src/components/sheet/` — интерактивный лист персонажа (по структуре официального бланка Fate Core).
  * `src/components/ai/` — модальные окна подсказок Gemini.
  * `src/components/common/` — переиспользуемые UI-компоненты (модалки, кнопки, инпуты).
  * `src/services/` — интеграции с Firebase, Gemini API, загрузка картинок, экспорт в PDF.
  * `src/context/` — управление состоянием (AuthContext, CharacterContext).
  * `src/types/` — TypeScript интерфейсы.
  * `src/config/` — пресеты (Ведьмак / Универсал).
* **Стиль кода:** ES Modules (`import`/`export`), деструктуризация, читаемые имена на английском, комментарии к сложной логике Fate на русском.
